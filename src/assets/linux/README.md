# Tux, la mascotte de Linux

`tux.svg` est l'image de Tux utilisée en haut de la page Linux (`/<langue>/services/linux/`).

- Source : https://commons.wikimedia.org/wiki/File:Tux.svg (fichier téléchargé le 27/11/2026, non modifié).
- Auteurs : Larry Ewing (dessin d'origine, réalisé avec The GIMP), Simon Budig (version vectorielle),
  Garrett LeSage (version SVG, https://github.com/garrett/Tux).

Le crédit est affiché sur la page, dans la note sur les marques (`trademarks` de l'offre `linux`,
dans chaque fichier de langue). Si l'image est retirée, retirer aussi ce crédit.

C'est la seule image de marque du site : les autres noms cités (CachyOS, Steam, Ubuntu, Debian…)
restent écrits en toutes lettres, sans logo.
